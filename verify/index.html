Verified Record

Check our numbers against the XRP Ledger

Every evening we save a fixed set of the figures we publish, exactly as we served them, and write one fingerprint of the whole set to the XRP Ledger. A fingerprint is a SHA3-512 hash. Change one digit in any figure and the fingerprint no longer matches.

That means you don't have to take our word for a past number. Pick a day below and your browser rebuilds the fingerprint itself, then compares it with the one on the ledger. The full saved figures for each day open up 7 days later.

    Check it yourself, without this page

    Each record's fingerprint is SHA3-512 of a zero byte followed by the record's exact bytes. Fingerprints are paired in name order and each pair is hashed as SHA3-512 of a one byte, the left and the right. A leftover at any level moves up unchanged. The last hash standing is the root.

    The root is written once a day from account rwty5XRq5zrqTZ7XMLgk3EqQ76V3SY8Gwy as a small readable memo labeled xrpl-utilities/verified-record. Only that account's own transactions count.

    Prefer a script? Download the checker (Python, standard library only, MIT). It reads the anchor straight from an XRP Ledger server you choose.
