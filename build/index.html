Build with XRPL data

Every figure on this site is also an API your code can call. Send one HTTP request, pay $0.01 to $0.25 for it, and get back JSON your system can act on. There’s no account, no API key and no subscription. Each call pays for itself in RLUSD, XRP or USDC.

See it in use Pricing

How one call works

  1. 1. Ask

    Your code sends a normal GET request.

    GET pulse.xrpl-utilities.io/bundles/xrp-market-briefing
  2. 2. Pay

    The first answer is HTTP 402 with three ways to pay: $0.05 in RLUSD or XRP on the XRP Ledger, or in USDC on Base. An x402 client library pays and asks again for you, in a few seconds.

  3. 3. Use the answer

    You get JSON with a plain-English summary, the key_numbers your code reads, and a provenance stamp naming the validated XRP Ledger it was served at. Check it yourself.

Set up once

These examples use Python and the x402-xrpl library, paying in XRP from your own wallet. Any x402 client works, in any language, on any of the three payment options.

Every use case below then comes down to one line, get(…), and a few lines of your own logic on what comes back.

from x402_xrpl import X402RequestsSession

def pay_in_xrp(accepts, *_):
    return next(
        a for a in accepts
        if a["network"] == "xrpl:0"
        and a["asset"] == "XRP"
    )

session = X402RequestsSession(
    wallet=wallet,
    rpc_url="https://YOUR_XRPL_RPC",
    payment_requirements_selector=pay_in_xrp,
)

def get(path, **params):
    resp = session.get(
        "https://pulse.xrpl-utilities.io" + path,
        params=params,
    )
    # a 402 here means the payment did not go through
    resp.raise_for_status()
    return resp.json()

A trading bot checks the market before it quotes

Who: market makers, quant desks, treasury teams.

Without it: you run your own ledger watcher, keep track of which wallets belong to which exchange, follow Ripple’s escrow and rebuild the order books yourself.

The call: $0.05
b = get("/bundles/xrp-market-briefing")
k = b["key_numbers"]

if k["exchange_net_direction_24h"] == "distributing":
    widen_spreads()   # XRP is moving onto exchanges

impact = k["sell_10m_usd_slippage_bps_xrp_rlusd"]
if impact is not None and impact > 5000:
    cap_order_size()  # a $10M sell would move the price over 50%

post_to_desk_chat(b["summary"])
