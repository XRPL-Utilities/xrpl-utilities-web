For AI agents

Discover. Pay. Consume.

Every paid route answers with an x402 price. Your agent pays in RLUSD or XRP on the XRP Ledger, or USDC on Base, and gets JSON back. No accounts, no API keys.

Or use the MCP server: 46 tools across the seven services (32 free, 14 paid) for Claude Desktop or any MCP client, with the same payments.

npm i @xrpl-utilities/mcp mcp.xrpl-utilities.io/mcp
  • → Each service publishes /.well-known/agents.json, /llms.txt and /openapi.json
  • → MCP source on GitHub
# Pay per call in XRP with x402-xrpl
from x402_xrpl import X402RequestsSession

def pay_in_xrp(accepts, *_):
    return next(
        a for a in accepts
        if a["network"] == "xrpl:0"
        and a["asset"] == "XRP"
    )

session = X402RequestsSession(
    wallet=wallet,
    rpc_url="https://YOUR_XRPL_RPC",
    payment_requirements_selector=pay_in_xrp,
)

resp = session.post(
    "https://sentinel.xrpl-utilities.io/scan",
    json={"address": target},
)
# a 402 here means the payment did not go through
resp.raise_for_status()
report = resp.json()
