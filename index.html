For AI agents

Discover. Pay. Consume.

Every paid route answers with an x402 payment request. No API keys or accounts: your agent reads the manifest, pays, and gets JSON back.

Or use the MCP server: 44 tools across the six services (29 free, 15 paid) for Claude Desktop or any MCP client, with the same payments. Hosted at mcp.xrpl-utilities.io/mcp or npm i @xrpl-utilities/mcp.

  • → Each service: manifest at /.well-known/agents.json
  • → Plain-text summary at /llms.txt
  • → OpenAPI spec at /openapi.json
  • → MCP server at github.com/XRPL-Utilities/xrpl-utilities-mcp
# Pay per call in XRP with x402-xrpl
from x402_xrpl import X402RequestsSession

def pay_in_xrp(accepts, *_):
    return next(a for a in accepts
                if a["network"] == "xrpl:0" and a["asset"] == "XRP")

session = X402RequestsSession(
    wallet=wallet,
    rpc_url="https://YOUR_XRPL_RPC",
    payment_requirements_selector=pay_in_xrp,
)

resp = session.post(
    "https://sentinel.xrpl-utilities.io/scan",
    json={"address": target},
)
resp.raise_for_status()  # a 402 here means the payment did not go through
report = resp.json()
